# v0.1: Canadian open data, ingested daily and tested

First release of Canada Data Migration: a small, public pipeline that ingests four Canadian economic series every day, models them with dbt and tests every change on Linux and Windows.

## What it does

- Ingests the USD/CAD exchange rate and the Bank of Canada policy rate (Valet API), and Ontario CPI and the Ontario unemployment rate (Statistics Canada WDS), from 2017 to today. Runs are incremental and idempotent, and the raw responses are kept with a hash.
- Models the data with dbt on DuckDB: staging, a star schema (`dim_date`, `dim_indicator`, `fct_observation`) and a monthly mart, with 57 data tests, a unit test and a freshness check per series.
- Runs every day on GitHub Actions against the live APIs, and checks every pull request on Ubuntu and Windows without calling the APIs.
- Publishes the dbt docs and a chart of the monthly mart to GitHub Pages after each daily run.

## Run it

```powershell
git clone https://github.com/manuelrpmca/canada-data-migration.git
cd canada-data-migration
uv run cdm run
```

Only [uv](https://docs.astral.sh/uv/) and Git are needed; no accounts or keys.

## Limits

DuckDB only, four series, no reconciliation yet. Alerting is GitHub's email on a failed run.
