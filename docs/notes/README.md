# Milestone notes

One short note per milestone: what was done, why, and how to talk about it. The owner reviews each note and runs the milestone on their own machine before it closes. Keep each note under one page.

Template:

```markdown
# MN. Title

Date closed: YYYY-MM-DD · Owner hours: N

## What was done
Three to six bullets, with links to the pull requests.

## Why it was done this way
The two or three decisions that matter, with links to ADRs.

## Measured results
Only numbers from real runs, with the date and command that produced them.

## What I would say in an interview
Two or three sentences in plain words.

## What I learned / what surprised me
One or two bullets.
```
